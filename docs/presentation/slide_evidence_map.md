## Verified project facts used in slides

- Dataset: UCI Machine Learning Repository dataset 697, *Predict Students' Dropout and Academic Success*. The project records 4,424 rows, 36 predictors, and three observed targets: Dropout, Enrolled, Graduate. The source institution is Portuguese.
- Model comparison: Logistic Regression, Random Forest, and Gradient Boosting; selected candidate is Logistic Regression on the project comparison criterion.
- Held-out test set: 885 rows; macro-F1 `0.715504`, accuracy `0.755932` (slide display rounds to `0.716` and `0.756`).
- The app's support chatbot is deterministic regular-expression intent routing with prepared responses. It is not a large language model, is not clinical care, and does not send messages to a remote AI service.
- No HELB, HEF, M-Pesa, or Kenyan institutional records are model inputs. Kenyan-campus support examples describe a proposed human referral context, not a validated Kenyan prediction service.
